## Limits

| Scope | Limit | Window | Configurable |
| :-- | :-- | :-- | :-- |
| Per API key | **1,000** requests by default | 1 minute | Yes, 10 to 100,000 per key |
| `/auth/{guard}/*` endpoints | **10** requests | 1 minute, per IP and route | No |
| PDF generation (dashboard) | 30 requests | 1 minute | No |

Every request made with a key counts toward that key's limit, including auth requests. The auth endpoint limit protects against password guessing and sign-up spam.

## When you exceed a limit

```http
HTTP/1.1 429 Too Many Requests
Content-Type: application/json

{ "message": "Rate limit exceeded." }
```

The window resets 60 seconds after the first counted request.

## Retry with backoff

```javascript
async function withRetry(fn, attempts = 4) {
  for (let i = 0; ; i++) {
    try {
      return await fn();
    } catch (err) {
      if (err.status !== 429 || i >= attempts - 1) throw err;
      const delay = Math.min(60_000, 1000 * 2 ** i) + Math.random() * 250;
      await new Promise((r) => setTimeout(r, delay));
    }
  }
}
```
