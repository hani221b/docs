A **hook** is a small Go program that Bludia runs at a point in a record's lifecycle. Use hooks for business rules that field validation can't express, and for side effects like sending emails.

```text
POST /collections/bookings
        │
        ▼
  beforeInsert hook  ── can change the record, or Abort() to reject it
        │
        ▼
  record saved (transaction committed)
        │
        ▼
  afterInsert hook   ── runs asynchronously: send email, update other records
```

## At a glance

| | |
| :-- | :-- |
| **Language** | Go (compiled with TinyGo to WebAssembly) |
| **Attached to** | One collection + one event |
| **Events** | `beforeInsert`, `afterInsert`, `beforeUpdate`, `afterUpdate`, `beforeDelete`, `afterDelete` |
| **Limit** | One hook per collection per event |
| **Sandbox** | No network or file system; talks to Bludia through the SDK |
| **SDK can** | Read/modify the current record, query/insert/update/delete records, send messages, log, abort |
| **Default limits** | 10 s timeout, 32 MB memory (max 30 s, 128 MB) |
| **Versioning** | Every save is a new version; you choose the current one |
| **Observability** | Each run is logged with status, duration, resources, and your log lines |

## A first hook

```go
package main

import (
	"strings"

	"bludia"
)

// beforeInsert on "customers": normalize the email and block duplicates.
func main() {
	ctx := bludia.GetContext()

	record, err := ctx.Record()
	if err != nil {
		bludia.Abort("Could not read the record")
		return
	}

	email, _ := record["email"].(string)
	email = strings.ToLower(strings.TrimSpace(email))
	record["email"] = email

	taken, err := ctx.Collection("customers").Where("email", bludia.Eq, email).Exists()
	if err != nil {
		bludia.Abort("Could not check for duplicates")
		return
	}
	if taken {
		bludia.Abort("A customer with this email already exists")
		return
	}

	ctx.SetRecord(record)
}
```
