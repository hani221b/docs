## Your frontend

Host your frontend anywhere: Vercel, Netlify, Cloudflare Pages, your own servers, or app stores. Point it at your project's API base URL and add its origin to your API key's [allowed origins](/api/cors).

## Environments

Separate development from production so tests can't touch live data:

| Approach | How |
| :-- | :-- |
| **Separate projects** (recommended) | One project for development or staging, one for production. Same schema, different data and keys |
| **Key environments** | Label keys `development`, `staging`, or `production` to tell traffic apart. They share the project's data |

## Observability

| What | Where |
| :-- | :-- |
| API key usage | Keys list: last used time and last IP |
| Hook runs | Hooks → Executions, with logs and resource usage |
| Scheduled function runs | Function → Runs |
| Imports and exports | Progress and status in their screens |
| Record changes | Record → History |
| Errors | `request_id` in error responses; share it with support |
