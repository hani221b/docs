# Introduction

Bludia is the unified development and infrastructure platform for building, deploying, and hosting application backends without starting every project from scratch.

Bludia provides the core infrastructure your application needs: databases, REST APIs, authentication, authorization, backend logic, messaging, and hosting, all managed from a single platform.

Instead of spending days (and billions of AI tokens) rebuilding the same CRUD operations, authentication systems, permissions, API endpoints, background jobs, and infrastructure for every project, Bludia gives you the foundation so you can focus on building the product itself.

> **Bludia is currently in beta.** The platform is actively evolving, and APIs, features, and interfaces may change as we continue improving the product.

## What is Bludia?

Bludia is designed to sit between your frontend and end-users.

You build your application using the technologies you already know, such as React, Next.js, Flutter, JavaScript, TypeScript, or any other client capable of consuming an API, while Bludia provides the backend services behind it.

## What can you build?

Bludia is designed for a wide range of applications, including:

- Internal management systems
- Admin panels
- CRM systems

- Business dashboards
- Customer portals
- Reporting systems
- SaaS applications
- Mobile application backends
- Directories and marketplaces
- Operational and workflow systems
- Custom business applications

The same backend capabilities can be combined differently depending on what you are building.

For example, a booking application might use:

**Collections** → customers, bookings, services, staff

**Authentication** → customer and staff guards

**RBAC** → administrators, managers, staff

**API** → frontend and mobile application communication

**Hooks** → booking validation and business rules

**Messaging** → booking confirmations and notifications

**Reports** → revenue, bookings, staff performance

## Core capabilities

### Database and data modeling

Create collections and define the data your application needs.

Bludia supports fields, relationships, records, search, filtering, sorting, pagination, and other data operations.

Learn more in [Database](/database/overview).

### REST API

Every project can expose its backend functionality through APIs that your frontend or external applications can consume.

You can connect Bludia to:

- React
- Next.js
- Flutter
- JavaScript applications
- Mobile applications
- Custom frontends
- External services

Learn more in [API](/api/overview).

### Authentication

Build application authentication around your own data model.

Bludia authentication guards can connect authentication to your project's user collection and provide the foundation for login, sessions, verification, and authenticated API access.

Learn more in [Authentication](/authentication/overview).

### Authorization

Control what authenticated users can access using roles and permissions.

Bludia supports role-based access control and authorization rules that allow you to define which users can perform specific operations.

Learn more in [Authorization & Security](/security/overview).

### Backend logic

When configuration alone isn't enough, use Bludia Hooks to run custom backend logic at different points in your application's lifecycle.

Hooks can be used for things such as:

- Validation
- Data transformation
- Business rules
- Notifications
- Integrations
- Custom calculations
- Automated backend operations

Learn more in [Hooks](/hooks/overview).

### Messaging

Connect your backend logic to email and other messaging capabilities.

Create reusable templates, configure email connections, and send messages from your application or backend logic.

Learn more in [Messaging](/messaging/overview).

### Reports

Turn application data into useful business reports and dashboards.

Reports can be used for operational systems, management dashboards, analytics, and other applications where raw records need to become useful information.

Learn more in [Reports](/reports/overview).

### Hosting

Bludia is not only a backend builder.

The platform is designed to provide the infrastructure required to run your application in production, including deployment, domains, SSL, backups, logs, and other hosting capabilities.

Learn more in [Hosting & Deployment](/hosting/overview).

## How Bludia works

A Bludia project generally follows this workflow:

### 1. Create a project

Create a project for your application and configure its environment.

### 2. Model your data

Create collections, define fields, and establish relationships between your data.

### 3. Configure your API

Bludia exposes your project data and operations through its API.

### 4. Add authentication and authorization

Configure authentication guards, users, roles, and permissions according to your application's requirements.

### 5. Add backend logic

Use Hooks when your application requires custom business logic.

### 6. Connect your frontend

Connect your React, Next.js, Flutter, mobile, or custom application to your Bludia API.

### 7. Set up API keys

Decide who can consume your application API and under which rules.

### 8. Deploy and run

Use Bludia's infrastructure and hosting capabilities to run your application in production.

## Bludia is not your frontend

Bludia does not require you to replace the technology you use to build your user interface.

You can continue using the frontend framework and tools you prefer.

This means you can build a completely custom frontend while using Bludia as the backend infrastructure underneath it.

## Bludia vs building everything yourself

Building a backend from scratch gives you maximum control, but it also means repeatedly implementing and maintaining the same infrastructure.

A typical project may require:

- Database models
- CRUD endpoints
- Validation
- Authentication
- Authorization
- API authentication
- Search and filtering
- Pagination
- Email delivery
- Background processing
- Business logic
- Logging
- Backups
- Deployment
- Server configuration
- Security

Bludia provides these capabilities as reusable infrastructure so you can spend more time on the parts of your application that make it unique.

## Built for developers and teams

Bludia is designed for developers, agencies, freelancers, startups, and teams that need to build business applications quickly without repeatedly rebuilding the same backend foundation.

You can use Bludia when you want to:

- Build a project faster
- Reduce technical debt to nearly zero
- Avoid repetitive backend boilerplate
- Connect multiple frontends to the same backend
- Build internal systems for businesses
- Prototype and validate applications
- Deliver client projects faster
- Maintain business applications without a large backend codebase
- Keep control over your application's data and business logic
