Messaging lets your backend send transactional messages, like booking confirmations or verification codes, without building an email system.

```text
Hook or auth flow ──► Template "Booking confirmed" ──► Channel "SMTP (Postmark)" ──► sarah@example.com
                       Subject: Your booking on {{date}}
                       Body:    Hi {{name}}, ...
```

## Ways to send

| Trigger | How |
| :-- | :-- |
| A record changes | `ctx.Msg().Send(...)` in an [after hook](/hooks/sdk-reference#messaging) |
| A user registers (verification) | Configure the guard's [email verification](/authentication/email-verification) channel and template |

## Example: send from a hook

```go
ctx.Msg().Send(bludia.MsgSendRequest{
	Channel:  "email",
	Template: "Booking confirmed",
	To:       "sarah@example.com",
	Data:     map[string]any{"name": "Sarah", "date": "1 Dec, 10:00"},
})
```

Messages are queued and sent in the background, so hooks return quickly.
