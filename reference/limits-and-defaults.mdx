## API

| Item | Default | Limit |
| :-- | :-- | :-- |
| Requests per API key | 1,000 / minute | 10 – 100,000 / minute (configurable) |
| Auth endpoints (`/auth/{guard}/*`) | | 10 / minute per IP and route |
| Page size (`limit`) | 20 | 100 |
| Sort columns | `created_at` | `created_at`, `updated_at`, `published_at`, `id` |
| CORS preflight cache | 3,600 s | |

| Password minimum length | 8 | Add stricter rules on the field |
| Password reset token | 60 min, single use | |
| Email verification code | 6 characters | |

| Password reset | On | Per guard |

## Scheduled functions

| Item | Limit |
| :-- | :-- |
| Interval (`every.amount`) | 1 – 1000 minutes, hours, days or weeks |
| Records per run (`for_each.limit`) | 1 – 1000 (default 100) |
| Time for one `for_each` run | 10 minutes, then it stops early |
| Missed runs after downtime | Run once |
| "Run now" | 60 / minute |
